# Trial Chamber Tracker

Клиентский мод для Fabric (Minecraft 1.21.4). Показывает, сколько испытательных
спавнеров и хранилищ осталось в Испытательной камере (Trial Chamber).

## Возможности
- Счётчик спавнеров и хранилищ слева снизу (положение меняется на J)
- Подсветка целей и линия к ближайшей (меню на H)
- Расстояние до целей
- Статистика: зачищено, открыто, камер посещено
- Сообщение и звук, когда камера зачищена

## Требования
- Minecraft 1.21.4
- Fabric Loader и Fabric API

## Клавиши
- H: меню подсветки
- J: перемещение счётчика

## Важно
Подсветка сквозь стены на многих серверах запрещена. Проверяй правила сервера.
